  the behavior-neutrality argument HOLDS for the render trio.
- The guard really is one-sided: the oc-side test has 9 `assertNotIn` lines, the agy-side test checks
  `Heartbeat` alone.
- `Heartbeat` really is already fixed (`agy_runipd.py:43`), so F-4 is correct and a literal execution

- `selectors.py` really declares no `__all__`, so F-6's hazard framing is accurate.
- F-5's reference counts are accurate (`Palette` 11 agy / 14 oc; 7 test files reference it).

Two problems dominated, and both were found by checking the plan's premises against the code rather
than by reading its prose. The first is an INCOMPLETE deletion that would have left the same defect
one layer down. The second is the plan's one genuine behavior risk, and it is invisible to the very
AST test the plan relies on for safety.
