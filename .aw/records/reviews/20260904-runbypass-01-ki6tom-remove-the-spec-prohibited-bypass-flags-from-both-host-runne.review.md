was correctly skipped.

THE PLAN WAS AUTHORED AT `d0919400` AND THE TREE HAS MOVED UNDER IT. `uyeko5` (`runflags-01`), which
this plan treats as a pending sibling to avoid running concurrently with, is now EXECUTED (finalized in
`251b7399`). Every line number the plan cites is stale, and more importantly `uyeko5` introduced a
shared data-driven flag registry, so the correct SHAPE of the fix is now an open question rather than
an obvious per-host edit.

WHAT THE PLAN GOT RIGHT, and it is genuinely good work: F-3's central insight that the opencode
violation is invisible to grep because `BooleanOptionalAction` generates the negation is correct,
non-obvious, and drives the right test design. F-5's identification of the opposite verification
defaults, and the refusal to harmonize them under cover of a conformance fix, is exactly the discipline
this change needs. F-6's separation of the CLI flag from the run-state key is correct and load-bearing.
E-04's isolation of the one real design question, and OQ-01's honest `Blocking: yes`, are right. The
2026-09-05 annotation recording the maintainer's per-model-routing point is a model of how to carry a
conversation into a plan without pretending it answered the question.

THE BLOCKER IS THAT THE PLAN'S SELF-DECLARED CENTERPIECE WAS FORBIDDEN. E-02 required flipping agy's
`--dangerously-skip-permissions` default to opt-in, called it "the real safety defect", and argued it
"must land even if OQ-01 stalls E-04". Approved spec `7ckptx` R4.1c forbids exactly that to any plan,
on recorded operational evidence and an explicit maintainer ruling; a code comment says "Do NOT
'harden' it"; and a test class exists whose stated purpose is to fail if it is flipped, asserting the
literal source strings E-02 would have edited. This is the one finding that could not be fixed by
adding evidence, because the WORK ITSELF was prohibited. The item is replaced, not softened: E-02 is
now an alias-only removal whose validation proves the opposite of what the original demanded.

Two smaller measurement errors compounded the same theme of an audit that stopped one level too early:
the oc violation is on TWO subparsers (`resume` carries it too, so the plan's fix would have left the
spec violated while its test reported success), and `--skip-audit` already conforms, so only three of
the four named spellings are live violations.
