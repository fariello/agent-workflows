CONFIRMED SOUND, AND THE DIAGNOSIS IS THE PLAN'S STRONGEST PART. The defect is real and reproduces end
to end: `install-workflows.py --diff` into a throwaway repo prints 213 proposed-file headers with ZERO
under `.agents/skills/`, while a real apply into a throwaway repo writes 92 files there. F-1's located
cause is exactly right. F-3 holds: `install_into_repo` composes `{**shim_members, **skill_members}` and
passes it to both `install_all` and `prune_stale`, so the fix really is a missing call rather than a
design change. F-4 holds and I strengthened rather than doubted it: `show_install_diffs` has exactly one
caller, every skill member's value is a `str` (which is what its `content.encode("utf-8")` requires),
and shim and skill keys have ZERO overlap, so the one-line merge cannot drop a member and the renderer
needs no change. F-5 holds, verified against `kvfsak`'s own text: E-05's deliverable is passing the
merged map to `prune_stale` and its V-05 evidence is re-install and orphan-prune output, with nothing
about the diff renderer, so this is a genuine gap and not a re-do. F-6 holds (`pytestmark` at `:32`,
`addopts` excluding `slow` at `pyproject.toml:169`). F-7 re-verified by running it: `10 passed in
13.00s`. F-8 holds and its deferral is right. E-01's claim that the branch already has all three inputs
is correct (`target_layout`, `workflows`, `plan.source_root` are all bound there). And the spec-sync
reading is correct: no spec in the 30-file tree governs the preview's member set, so no amendment is
owed.

WHAT THIS ROUND CHANGED ABOUT THE PLAN'S SHAPE. Nothing about WHERE to fix the code; the one-line E-01
survives essentially untouched. Everything about HOW THE FIX IS PROVEN AND DESCRIBED. The pattern
across PR-001, PR-002 and PR-005 is one failure repeated three ways: the plan reasoned about the
verification instead of performing it, and each reasoned-about step turned out to be broken when run.
The prescribed test passes before the fix. The prescribed command errors out. The prescribed grep shows
the defect as absent. A plan whose validation section is otherwise rigorous about demanding pasted
evidence nonetheless specified three evidence-gathering steps that had never been executed once. The
second, smaller theme is precision drift: two code sites placed in the wrong function, and four
numbers plus a suite baseline that were already stale at authoring time. Both themes are now closed
with measured replacements rather than with softer wording.
