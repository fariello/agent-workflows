## Workflow history
- 2026-09-22 created (aw backlog): Found while executing runnerlayer 01 (9kmbr0), which classifies the oc-to-agy import surface and moves nothing, so this is reported rather than fixed. WHAT IS WRONG: oc_runipd.process_backlog_close builds its commit message with the literal host label 'aw oc run' (agent_workflows/oc_runipd.py:2007, f"closed by aw oc run: IPD {item['id6']} executed "), and agy_runipd imports and calls that SAME function object rather than defining its own, so an ANTIGRAVITY-driven run writes a commit message on main claiming an opencode run closed the item. MEASURED, not inferred: stripping comments AND docstrings from all 56 oc-to-agy imported definitions and scanning the remainder leaves exactly ONE with an 'oc' token in EXECUTABLE code, and it is this one; four others (queue_sort_key, run_order_rationale, render_runs_pointer, dependency_status_detailed) carry such a token in PROSE only and are correct. WHY IT IS A BUG AND NOT A CHORE: the wrong label lands in a COMMIT MESSAGE on main, which is durable, human-read output that attributes work to the wrong driver, so a maintainer auditing which runner closed an item is actively misled by the record; it is a wrong answer rather than a slow one. WHY IT IS NOT A CLASSIFICATION CHANGE: a host label is a PARAMETER, not an opencode concept, so the function stays host-NEUTRAL under the criterion in tests/test_runner_layering.py. LIKELY FIX, with an in-repo precedent to copy rather than invent: inject the label the way runner_shared.integrate_lane_branch already does, where the shared function gives the host label NO DEFAULT precisely so a mis-binding cannot be silent and each runner binds its own ('aw oc run' / 'aw agy run'); see HOST_LABELS and test_the_host_label_has_NO_DEFAULT_in_the_shared_function plus test_each_runner_binds_its_OWN_host_label in tests/test_runner_shared.py. If runnerlayer 02 (1f7xno) re-homes this function into runner_shared, the label becomes that plan's parameter question; if it does not, this item carries the fix.
