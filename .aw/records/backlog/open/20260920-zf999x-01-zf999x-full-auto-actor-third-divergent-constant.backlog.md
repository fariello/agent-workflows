## Workflow history
- 2026-09-20 created (aw backlog): Found while authoring spec llbr2b (plan u06zo2) from backlog rxya25, at HEAD 2c316ef0. MEASURED: three constants exist. oc_runipd.py:869 FULL_AUTO_ACTOR = 'aw oc run --full-auto'; agy_runipd.py:966 = 'aw agy run --full-auto'; runner_shared.py:13503 = 'aw-driver/full-auto'. The two host copies share one message (oc_runipd.py:871, agy_runipd.py:967: 'auto-approved by --full-auto: review readiness cleared (not human approval)'), while the shared copy at runner_shared.py:13502 reads 'Auto-approved via --full-auto (review passed all gates)'. The shared pair HAS NO READER: both hosts import runner_shared and then define their own, and the only two tests asserting an actor reaches the argv assert the HOST constants (tests/test_oc_runipd.py:1428, tests/test_agy_runipd_cli.py:1121). WHY THIS IS A BUG AND NOT MERELY UNTIDY: the rununify Set is actively consolidating these hosts onto runner_shared, and the obvious consolidation (delete the host copies, use the shared ones) would (1) change the recorded actor on every --full-auto transition from a host-identifying string to an opaque 'aw-driver/full-auto', losing which host performed it, and (2) replace an honest message that says review READINESS cleared with one claiming the review 'passed all gates', which asserts more than the predicate (plan_readiness.is_plan_review_approved) actually checks. That second half is an attestation-honesty regression in exactly the area spec 20260815-0151-01 and 97df1z OQ-02 exist to protect. WHY USER-PERCEPTIBLE, which is what earns work-kind bug here: the actor string and message are written into the artifact's committed Workflow history, so a wrong value is durable, visible to any human reading the plan, and misstates what cleared the plan. FIX DIRECTION (not decided): either delete the unread shared pair, or make it the single definition with the HOST-identifying value supplied through the existing HostLabels descriptor (runner_shared.driver_actor already takes labels as a parameter for exactly this) and the host message text preserved. Do NOT simply adopt the shared values. Spec llbr2b section 3.7 D-2 records the measurement and section 10 deliberately leaves the fix out of the policy rollout.
