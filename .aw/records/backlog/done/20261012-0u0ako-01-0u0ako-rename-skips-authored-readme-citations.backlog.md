MEASURED WHILE AUTHORING PLAN 1v2e1o (graduating xp6o3v). `artifact_refs.plan_reference_rewrites_with_warnings` skips any scanned file whose name is in `artifact_refs._SKIP_NAMES` (`README.md`, `INDEX.md`, `STATUS.md`), on the stated premise (commit 674f2c687, idxuntrack `4r0qp1`) that these are GENERATED manifests the caller regenerates. INDEX.md and STATUS.md are generated and gitignored, but README.md is not: the 26 tracked `.aw/records/**/README.md` files are installer templates or hand-authored bundle READMEs, and none is regenerated by a rename. So a README citation of a renamed record is silently left dangling.
