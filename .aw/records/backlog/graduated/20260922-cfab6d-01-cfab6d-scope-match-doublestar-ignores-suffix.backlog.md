## Workflow history

- 2026-09-22 created (aw backlog): Found while executing plan 8u6770 (planprio Order 02), when 'aw commit 8u6770' ACCEPTED a backlog item path under a plan whose declared Scope-Paths is only '.aw/records/plans/pending'. THE DEFECT is in ipd_lifecycle._scope_match (ipd_lifecycle.py:1969-1998). For a pattern containing '**', when fnmatch fails it falls back to: prefix = pat.split('**',1)[0].rstrip('/'); return bool(prefix) and (p == prefix or p.startswith(prefix+'/')). That DISCARDS EVERYTHING AFTER THE '**', including the filename component, so the pattern degenerates to a bare directory prefix. MEASURED at HEAD af28bde5: _scope_match('.aw/records/backlog/open/anything.backlog.md', '.aw/records/**/index.md') returns True, as does the same pattern against a .spec.md, a research file, and a comms inbox file; the allowance intended to let a plan refresh an index.md in fact admits EVERY path under .aw/records/<anything>/. THE HOLE IS NOT CONFINED TO THE IMPLICIT ALLOWANCES and that is what makes it high rather than medium: the same function evaluates an author's DECLARED Scope-Paths, so _scope_match('tests/anything.txt','tests/**/*.py') is True and _scope_match('agent_workflows/README.md','agent_workflows/**/*.py') is True. Any plan declaring a '**'-with-suffix pattern therefore has a WIDER real scope than it declares, and both the pre-commit refusal in work_cmd.run_commit (work_cmd.py:556-570, via work_cmd._in_scope) and the finalize-time ownership test ipd_lifecycle._working_tree_path_is_owned consult this one predicate, so the commit gate and the scope-drift reconciliation are loose in exactly the same way. WHAT IT DOES NOT DO, stated so the severity is not overread: it does not widen scope ACROSS a declared prefix ('.aw/records/plans/**' still refuses a spec), it requires the author to have written a '**' pattern in the first place, and it loosens a check rather than corrupting data, so nothing is silently mis-written. The practical effect is an out-of-scope path being accepted into a commit and later NOT reported as scope drift. FIX SHAPE: the '**' fallback must keep matching the remainder after the '**' rather than dropping it (translate the pattern to a regex where '**' maps to '.*' across separators and '*' does not, or fnmatch against the suffix as well as the prefix). Note the comment above the branch already states the intended semantics ('dir/*.py should not match nested, but dir/**/*.py should'), so this is a straightforward implementation gap and not a design question. Pin it with a test table that includes the FOUR measured rows above plus the two negative rows that must keep refusing, because a naive fix that simply deletes the fallback would break the '.aw/records/**/index.md' allowance it exists to serve.
