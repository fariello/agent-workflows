## Open questions

### OQ-01: Should `resume`'s automatic integration be attempted for `merge-conflict` items as well as `integration-blocked`?

- Blocking: no
- Status: resolved
- Owner: none
- Resolution or deferral rationale: YES, ATTEMPT BOTH, because the attempt is cheap and the outcome is authoritative. `merge-conflict` means the gate previously found a real conflict against the main of that moment; main has since moved, so the conflict may be gone and the only way to know is to run the gate again.
