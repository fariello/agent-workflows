- `term.py` IS THE DECLARED SHARED HOME FOR WIDTH HANDLING and this plan adds to it rather than creating a new module. Its display-width section already holds `is_zero_width`, `visible_width`, `_pad_visible` and `truncate_visible`, and spec `uonrjg` Section 9.4 names a "shared display-width helper" as the sanctioned route while forbidding "per-renderer width guesses". `attention.py`, `cli.py`, `ipd_lint.py`, `run_viewer.py` and `render_stream.py` all already consume `visible_width` from it.
- KEYWORD-ONLY OPTIONS ARE THE SECTION'S EXISTING SHAPE. `truncate_visible(text, limit, *, ellipsis="")` is the sibling helper and puts its option after `*`; `pad_visible`'s `align` follows it.
- EVERY MODULE THIS PLAN TOUCHES ALREADY IMPORTS THE TERM MODULE, under an existing alias: `T` in `attention.py`, `_term_mod` in `cli.py`, `_T` in `ipd_lint.py` and `run_viewer.py` (all verified at review). No import is added by this plan.
- IN `cli.py`, `term` IS A `Term` INSTANCE AND `_term_mod` IS THE MODULE; THEY ARE NOT INTERCHANGEABLE. Corrected at review (PR-303): the authored bullet read "`_term_mod`/`term` in `cli.py`", which invites `term.pad_visible(...)`, an `AttributeError` since `pad_visible` and `visible_width` are module-level functions that a `Term` instance does not carry (measured: `hasattr(Term(), "visible_width")` -> False). Module functions go through `_term_mod`; styling methods such as `style_lifecycle_text` go through the instance. Both spellings appear side by side at this plan's own second `cli.py` site, so the distinction is live rather than pedantic.
- ASSERT BEHAVIOR, NOT STRUCTURE. `GUIDING_PRINCIPLES` P16 forbids tests that read production source with `inspect`/`ast`/regex, assert caller counts or symbol censuses, or pin bytes. So E-04 drives the function and asserts returned strings, and E-05's byte comparison is one-off evidence rather than a shipped test.
- WIDTH-PROPERTY TESTS ARE AN ESTABLISHED FAMILY HERE. `tests/test_term.py` already exercises `visible_width` and `truncate_visible` directly, and `tests/test_attention.py` and `tests/test_run_viewer.py` each assert a single `visible_width` across their rendered body lines. E-04 adds the missing member for the padding half.
- RUN THE SUITE BARE (`python3 -m pytest`). `pyproject.toml` `addopts` already supplies `-q -n auto --dist=worksteal` and the slow/livecorpus deselection; `-n0` makes it several times slower, a second `-q` suppresses the summary line this plan requires be pasted, and `-p no:randomly` disables the order randomization.
- WRITE SCRATCH PROBES UNDER `.aw/state/`, which `.aw/.gitignore` ignores (`/state/`). Authoring wrote its probe there and it never appeared in `git status --short`.
- Cite code by SYMBOL (`module.function`) or by a quoted content string, with a line number only appended to one of those and never alone: an offset expires before this plan executes (spec `ipd-structure-and-linting` Section 10.2; advisory `IPD-C801`).
