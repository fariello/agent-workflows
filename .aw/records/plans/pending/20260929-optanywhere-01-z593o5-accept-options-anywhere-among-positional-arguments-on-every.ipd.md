# IPD: Accept options anywhere among positional arguments on every aw leaf whose greedy positional can swallow them

- Date: 2026-09-29
- Kind: child
- Concern: A flag placed between or after positional arguments is REFUSED across the `aw` surface, because a `nargs="*"`/`nargs="+"` positional consumes greedily and argparse then reports the leftovers as `unrecognized arguments`. Measured on 25 leaves that declare their own flags, including `aw set`, `aw specs set`, `aw backlog set`, `aw ipd set`, `aw find`, `aw partition` and `aw adopt`. The failure is exit 2 with no hint that reordering would work, so an operator or agent that writes the arguments in a natural order is simply refused.
- Scope: Give the shared parser base class `cli._AwArgumentParser` a `parse_known_args` override that routes a leaf to argparse's own `parse_known_intermixed_args` when, and only when, that leaf is SAFE for it (a greedy positional present, and no `REMAINDER`/`PARSER` positional), falling back to today's behavior otherwise. Add a reentrancy guard, because on Python 3.9 through 3.12 the stdlib intermixed path calls `parse_known_args` back and a naive override recurses infinitely (measured, F-6). Add behavioral tests over the real parser tree. EXCLUDES the 33 leaves carrying a `REMAINDER`/`PARSER` positional (the forwarding and passthrough commands, F-4), EXCLUDES any change to `work_cmd`'s hand-rolled recovery helpers (F-5), and EXCLUDES declaring the flags that 8 config/workflow leaves are MISSING, which is a different defect the item conflates with this one (F-3, OQ-01).

It was MEASURED doing exactly that on all three interpreters before the guard was added. A reviewer should treat that as the highest-risk line in the change.

## Goal

Let an operator or agent write `aw <verb> <positional> --flag value <positional>` and have it work, on every leaf where that is expressible, instead of being refused with `unrecognized arguments` and no hint that reordering would help. Do it by delegating to argparse's own intermixed parser at the single shared base class, gated to the leaves where it is safe, rather than by hand-rolling an argv reordering pass that would have to re-derive which tokens take values.
