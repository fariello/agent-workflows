- INLINE HISTORY IS THE DURABLE HOME for specs and backlog items, per the maintainer's 2026-09-10 ruling recorded in `vhbvwz` OQ-01, because `.aw/.gitignore` ignores `records/history.jsonl` (verified: line 11). - NEWEST-FIRST IS THE WRITER'S CONTRACT, documented at length in `attention_contract.newest_history_record` and implemented by `status_set.apply_status_change`'s `insert(i + 1, ...)`. The bug class in this plan is code that predates that contract and still assumes last-in-order.

So the right move for any position-derived ordering defect is to defer to `2vev8j`, never to add a direction heuristic. Approved 2026-09-09; `- Blocks-Release: next`.
- `status_set.same_status_message_is_duplicate` IS THE ONE DEDUP RULE and it is artifact-neutral (verified at review against a spec block, a `note` token, and a multi-part actor). It lives in `status_set.py`, not `backlog.py`, and it deliberately compares the NEWEST record only so a genuinely new note reusing older wording still records.
