## Project conventions discovered (Step 0)

- A PROBE MUST ATTEMPT, NOT INSPECT, and this module publishes the measured counterexample in its own docstring section "WHY THE PROBE EXECUTES INSTEAD OF INSPECTING": every inspected signal (two sysctls, both binaries present) said "sandbox available" on a host where `unshare -Umr true` actually failed, so inspection would have granted hard mode and failed OPEN. The `HostSandboxCapabilities` docstring states the rule as "A field may only be set True by code that actually executed a probe for it." The line this plan deletes is the last violation of that rule in the module.
- AN UNPROBED CAPABILITY CLAIMS NOTHING. Every field on `HostSandboxCapabilities` defaults False, and a capability with no probe reports not-supported WITH THE REASON RECORDED in `probe_notes` rather than supported-by-assumption (`probe_runner_safety_capabilities`, and `_DECLARED_UNENFORCED` for the one field that is deliberately never probed). This is why E-03's False branch must carry an explanatory note and not merely return False.
- THE SIBLING FIX IS THE TEMPLATE, and it is executed: plan `qul11h` (`.aw/records/plans/executed/20260928-plsx3r-01-qul11h-...ipd.md`) fixed the OTHER half of this same identity branch by adding `_probe_session_resume`, wiring it before the platform gate, deleting the identity line, and pinning a true/true/false triple. Its review record carries four findings this plan inherits by analogy: the function-local import requirement (an import cycle, `oc_runipd` imports this module at module level), the re-entrancy guard needing a `finally`, the probe's real side effects, and the off-platform value change needing disclosure.
- CITE BY SYMBOL, NOT BY BARE LINE NUMBER. Cite code by SYMBOL (`module.function`) or by a quoted content string, with a line number only appended to one of those and never alone: an offset expires before this plan executes (spec `ipd-structure-and-linting` Section 10.2; advisory `IPD-C801`).
- THE CAPABILITY REPORT INTROSPECTS THE DATACLASS. `host_cmd._capability_rows` derives its rows from `caps.to_dict()` rather than a hand-written name list, with the comment recording why ("that is exactly how three fields once became structurally invisible"). So this plan adds no field and needs no report edit, and a probe note appears in the report automatically as the `why:` line.
- RUN THE SUITE BARE. `python3 -m pytest` is already quiet, parallel and fast-scoped via `addopts`; adding `-n0` makes it several times slower, a second `-q` suppresses the very summary line the execution contract requires pasting, and `-p no:randomly` disables the order randomization that surfaces order-dependence bugs.
