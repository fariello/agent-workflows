## Goal

Make a plan's permanent finalize record say what actually happened to every changed path outside its fence. Today a path the ownership filter disregards leaves NO trace in any durable artifact, so an executed plan whose execution went outside its declared fence is indistinguishable, forever, from one that stayed inside it. After this plan the executed plan and its lifecycle commit name every out-of-scope path that was disregarded on NO ownership evidence, alongside the evidence class that produced that verdict, so a human auditing an executed plan can see the deviation and a reviewer can tell an excused path from an absent one. The gate's VERDICT is deliberately unchanged: the same paths are demanded, the same finalizes succeed and refuse, and no exit code moves.
