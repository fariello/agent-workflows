## Project conventions discovered (Step 0)

- Cite code by SYMBOL (`module.function`) or by a quoted content string, with a line number only appended to one of those and never alone: an offset expires before this plan executes (spec `ipd-structure-and-linting` Section 10.2; advisory `IPD-C801`).
- STAGED SEVERITY IS THE HOUSE PATTERN FOR A NEW CORPUS-WIDE RULE, and the mechanism is exact: `artifact_core.drift_exit_code` returns nonzero for any finding whose severity is not `info`, so `info` is the ONLY tier that reports without failing. `check.ipd-uncarried-obligation` shipped at `info` for precisely this reason, its plan recording that `warning` "would have failed CI with 106 findings on a clean tree".
- THE SCOPE-PATHS MATCHER IS `ipd_lifecycle._scope_match` AND IT IS THE ONLY CORRECT READER OF THE GRAMMAR. Its documented branches: a trailing `/` or `/**` is directory-bounded; a glob is matched per segment with `**` spanning whole segments; and "a literal path: exact match, or a directory prefix (a bare `agent_workflows` covers the tree)". That last branch is the entire mechanism of this defect.
- A BARE DIRECTORY IN `Scope-Paths` IS ALREADY KNOWN-DANGEROUS, and the repository wrote down why in `ipd_lifecycle.scope_entry_is_literal_file`: a bare directory "contains no glob character yet matches by prefix, so it is NOT eligible" for scope widening, because "an agent could therefore convert a four-file fence into a repo-wide one". That reasoning was applied to WIDENING; this plan applies the same measured property to TARGET REACHABILITY.
- TERMINAL PLANS ARE APPEND-ONLY, NOT FROZEN, per `DECISIONS.md` D156: "Never change what an executed plan RECORDS (its steps, evidence, results, or status) ... An agent MAY append a dated `## Workflow history` line that points at later work." D156 also records that this was never tool-enforced, because the executed-transition hook deliberately allows such edits.
- `check_scope_path_target_stale` restricts itself to plans whose parent directory is `pending`, documenting that "terminal plans are history and would be 58 permanent findings". E-03 follows that precedent exactly.
