- Date: 2026-10-14

- Concern: `artifact_refs.plan_reference_rewrites_with_warnings` skips every file whose basename is in `artifact_refs._SKIP_NAMES` (`{"README.md", "INDEX.md", "STATUS.md"}`). Commit `674f2c687` (plan `4r0qp1` E-05) added that check to stop `aw rename` and `aw group` from rewriting and staging generated manifests (`INDEX.md`, which `.aw/.gitignore` ignores and the caller regenerates, and the tool-written `STATUS.md` from `aw plans --write-index`, which is tracked at `.aw/records/plans/STATUS.md` but is not regenerated by rename), but reusing `_SKIP_NAMES` (the non-record filename filter for record-enumeration loops) also excluded every `README.md` across `artifact_core.REFERENCE_SCAN_ROOTS`. Unlike `INDEX.md` and `STATUS.md`, `README.md` files are tracked, never regenerated by `aw rename` or `aw group`, and already scanned as citing documents by every dangling-citation and stale-path detector (`artifact_refs.dead_filename_citations`, `artifact_core.find_dangling_citations_counted`, `artifact_rename.find_unrewritable_path_citations`, and `doctor.probe_installed_doc_references`), and `artifact_core.SCAN_ROOTS` explicitly lists repo-root `"README.md"`. Consequently, renaming or regrouping a record cited in a `README.md` leaves the citation untouched during `aw rename`/`aw group` and manufactures a dangling citation (`doctor.dangling-doc-reference` / `dead_filename_citations`).
- Scope: IN: split the generated-manifest skip set (`_GENERATED_MANIFEST_NAMES = {"INDEX.md", "STATUS.md"}`) from the non-record filename filter (`_SKIP_NAMES = {"README.md", "INDEX.md", "STATUS.md"}`) in `agent_workflows/artifact_refs.py` so `artifact_refs.plan_reference_rewrites_with_warnings` scans `README.md` files while still skipping `INDEX.md` and `STATUS.md` and while `artifact_refs.dead_filename_citations` continues skipping `_SKIP_NAMES` when collecting target record filenames; add CLI-driven outcome tests in `tests/test_artifact_refs_rewrite.py` pinning `README.md` rewrites (research-bundle `README.md` facet-less and full-name/stem citations, repo-root `README.md` citation, and legacy-prefix short-handle citation in `.aw/records/backlog/README.md`) alongside the `INDEX.md`/`STATUS.md` skip invariant; and add one `- Fixed:` entry to `CHANGELOG.md`.
