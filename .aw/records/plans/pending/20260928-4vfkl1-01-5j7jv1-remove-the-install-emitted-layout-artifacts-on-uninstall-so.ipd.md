## Project conventions discovered (Step 0)

- `uninstall_repo`'s STEP-4 BLOCK IS WHERE FRAMEWORK-GENERATED NON-MANIFEST FILES ARE REMOVED, and it already handles `.aw/config`, `.aw/state`, `.aw/.gitignore`, the setup marker and finally the manifest. Each removal calls `_uninstall_remove`, `_record_changed` and `actions.append` together; a new removal that omits any of the three is inconsistent with every sibling.
- BOTH `uninstall_repo` AND `run_deep_cleanup` END WITH THE SAME "prune now-empty dirs under `.aw`, deepest first, then `.aw` itself" LOOP using `rmdir()` in a `try`. Pruning is therefore automatic once a directory's last file is removed, and no pruning change is needed for a fix that removes files.
- `emit_layout_artifacts` IS CALLED FROM INSIDE `install_into_repo` BY DESIGN, its own docstring explaining that this is the shared chokepoint reached by `aw install`, by `aw setup`, and by library callers. So every install emits these files and every uninstall must expect them.
- THE ARTIFACTS ARE DELIBERATELY GITIGNORED (`.aw/.gitignore` lists `system/layout.json` and `system/layout.schema.json`) to avoid install-time git drift. A consequence that matters here: `_git_file_state` returns `at_risk` for any untracked path, so anything that routes these files through `plan_deep_cleanup` makes them at-risk (F-05).
- SLOW-MARKED COVERAGE IS INVISIBLE TO THE CONTRACT-MANDATED RUN. `tests/test_installer.py` carries a module-level `pytest.mark.slow` and `addopts` carries `-m 'not slow'`, so a bare `python3 -m pytest` never executes it. New tests for this tree should be default-visible; plan `baxbdh` established that precedent with `tests/test_deep_cleanup_regenerable.py`.
- CLASS-SCOPED `pytestmark` DESELECTS PER CLASS while leaving sibling classes in the same module default-visible; plan `baxbdh` verified this at review and uses it to keep one real-install case slow while its classification cases run bare.
- RUN THE SUITE BARE (`python3 -m pytest`). `addopts` already supplies `-q -n auto --dist=worksteal -m 'not slow'`. Adding `-n0` makes it several times slower, a second `-q` suppresses the summary line this plan requires pasted, and `-p no:randomly` disables the order randomization. Use `-o addopts=""` only to reach the slow subset, and say so.
- THE `aw` CONSOLE SCRIPT MAY IMPORT `agent_workflows` FROM THE MAIN CHECKOUT rather than this lane, announcing on stderr `aw: invoked in checkout <lane> but imported agent_workflows from <main>; re-running with <lane>'s package`. Observed during authoring. Prefer `python3 -m agent_workflows` (or `AW_NO_REEXEC=1`) for any invocation used as evidence, and state which was used.
- WRITE THROWAWAY REPOS INSIDE THE LANE OR VIA pytest `tmp_path`. Authoring was denied external-directory write access outside an allowed scratch path; tests should use `tmp_path` or the existing `tests/support` helpers.
- Cite code by SYMBOL (`module.function`) or by a quoted content string, with a line number only appended to one of those and never alone: an offset expires before this plan executes (spec `ipd-structure-and-linting` Section 10.2; advisory `IPD-C801`).
