This plan is specifically about citations that rotted, so it uses none of its own.

P16's "one narrow exception" is a test whose SUBJECT IS the text (for example checking that published documentation does not cite deleted test files); it explicitly does not extend to production code. Nearly all of both deleted files' guard machinery falls on the forbidden side.
