## Goal

Make the one advisory in a long `aw check` report readable. After this plan, `aw check plans` prints one block per RULE with a severity badge and a count, worst severity first, and one `Next` line per distinct remediation, so a human or agent scanning the report can find what matters instead of losing it in a per-finding enumeration. A report that has no repetition in it renders exactly as it does today. THE DIRECTION OF THE PROBLEM HAS INVERTED SINCE AUTHORING and the Goal is restated to match measurement (PR-306): the authoring corpus was 19 findings dominated by errors with a lone `info` lost among them, while the review corpus is 56 findings of which 42 are `info` (35 from one rule), so it is now the handful of ERRORS that is lost among advisories. E-04's worst-severity-first ordering is what addresses the shape as it actually is.
