## Project conventions discovered (Step 0)

- CODE IS CITED BY SYMBOL, NOT BY BARE LINE OFFSET, per spec `ipd-structure-and-linting` Section 10.2 and advisory `IPD-C801`. This matters unusually much for this item, because BOTH of its line numbers are now wrong. Item 1's cited offset predates the `rununify` lifts that grew the module by roughly ten thousand lines, so the `holds_work` code it names now sits far below it inside `runner_shared.reconcile_item_on_interrupt`; item 2's cited offset now lands on the `def bound_expiry_reaper(` signature block rather than on the `reaper(process, run_dir=run_dir)` call it was describing.
