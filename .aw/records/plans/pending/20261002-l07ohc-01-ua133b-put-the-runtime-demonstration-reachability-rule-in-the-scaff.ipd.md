## Goal

`- Required evidence:` demand, instead of learning it from a reviewer's UNDER-SCOPE finding after the
plan is already written. The rule itself does not change; what changes is that the scaffold an author
starts from states it, and a test pins that it keeps stating it.

## Project conventions discovered (Step 0)

- THE TEMPLATES ARE GENERATED, NEVER HAND-EDITED. `tests/test_ipd_templates.py::TemplateParityTests` byte-compares both template files against `ipd_authoring.build_skeleton` output with the failure message `regenerate it`. So a template edit is ALWAYS a two-step: change the generator, then regenerate. Executed plan `uh9jsk` E-03 shipped exactly this two-step for this same constant, and executed plan `mzc019` recorded that the single-line addition breaks the parity pin and that breaking it is the point.
- THE PLACEHOLDER TUPLE IS THE ONE COUPLING THAT MATTERS, AND PERMANENT GUIDANCE IS DELIBERATELY EXCLUDED FROM IT. `ipd_authoring._AUTHORING_PLACEHOLDERS` means "still a stub"; `authoring_placeholders_resolved` returns False while any member is present. The generator's comment above `_SECTION_BODY[S.H_PROJECT_CONVENTIONS]` states the convention in full: permanent guidance an author is not expected to delete must NOT be listed there. That comment governs a sentence already shipped by this exact route (the citation-anchor convention), so this plan follows a shipped precedent rather than inventing one.
- ONE LINE ON PURPOSE IS THE SCAFFOLD'S OWN STATED VALUE. The same generator comment reads `ONE LINE ON PURPOSE: the skeleton's value is that it gets read, and every line added lowers the odds the next one is.` This is why E-02 appends ONE sentence rather than the review bullet's 1846 characters, and why the sentence is compressed to the three anchors plus the scope distinction.
- THE RULE'S WORD IS ALREADY OVERLOADED IN THE `assess` TREE, in a DIFFERENT sense. `lenses/bugs.md` says `fails on a reachable path` and `reachable paths as Blocker/High`, and `lenses/edge-cases.md` says `crash on a reachable path`; those mean "the defect is on a live code path", not "the demanded observation is producible". This is why E-02 requires the FULL name `Runtime-demonstration reachability` rather than a bare "reachability".
- THE INTRO HAS A TEST THAT LOCATES IT BY PREFIX AND PARSES IT BY REGEX. `tests/test_ipd_authoring.py::ScaffoldVocabularyIntroTests` finds the line via `candidate.startswith("Validation-state rule:")` and extracts the vocabulary via `Accepted validation results:\s*([^;]+);`. Appending after the existing sentences preserves both; inserting before the prefix or re-punctuating the vocabulary list would not.
- Cite code by SYMBOL (`module.function`) or by a quoted content string, with a line number only appended to one of those and never alone: an offset expires before this plan executes (spec `ipd-structure-and-linting` Section 10.2; advisory `IPD-C801`).
