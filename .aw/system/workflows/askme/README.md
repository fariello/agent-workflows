# askme

Ask the human the decisions that are genuinely theirs, one interactive prompt at a time, in plain
English with full context and a labelled recommendation, then record each answer in the artifact that
raised the question so it survives the session. Composition rules live in GUIDING_PRINCIPLES principle
12 and are referenced, not restated. Run `/askme`, or from any agent: "read and execute
`.aw/system/workflows/askme/askme.md`".
