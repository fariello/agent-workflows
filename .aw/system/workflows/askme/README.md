# askme

Ask or rewrite one decision question at a time with plain language and all context needed to answer.
Accept a current question, conversational instructions such as "that question again", or project
records to examine. Wait for answers and record project decisions. Explicitly noninteractive runs
preserve unanswered decisions without guessing. Run `/askme`, or from any agent: "read and execute
`.aw/system/workflows/askme/askme.md`".
