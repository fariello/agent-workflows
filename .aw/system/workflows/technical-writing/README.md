# technical-writing

The shared writing standard for all technical text: backlog items, specs, plans, research,
prompts, reviews, walkthroughs, documentation, commit messages, code comments, and reports.
It is a standard, not a command: there is no slash command and no manifest row. The installed
`AGENTS.md` block tells every agent to read and follow
`.aw/system/workflows/technical-writing/technical-writing.md` before it writes, revises,
reviews, or proofreads technical text, and the authoring and review workflows repeat that
instruction at the point of use.

`technical-writing.md` is the single authoritative copy. `aw install` copies it into every
managed repository with the rest of this bundle. Edit it here, never in an installed copy.
